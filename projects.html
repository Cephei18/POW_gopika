Echo — Autonomous Ecosystem Intelligence Platform

An AI-powered intelligence infrastructure platform built for the Base ecosystem to monitor governance, grants, ecosystem activity, and emerging opportunities in real time.

Designed and engineered a production-grade backend architecture using FastAPI, Redis, APScheduler, and Next.js with asynchronous polling pipelines and precomputed feed APIs for scalable data delivery. Built with a strong focus on systems engineering, operational reliability, and real-time coordination infrastructure.

  • Live: base-navigator.vercel.app
  • GitHub: Cephei18/base_navigator

featured project 05

Semantic Dependency Graph for Autonomous Tool Planning

A typed semantic execution graph and dependency planner for autonomous AI agents using Composio GoogleSuper and GitHub toolkits.

Instead of directly chaining APIs together, the system models tools through canonical semantic entities such as EMAIL_THREAD_ID, EMAIL_ADDRESS, GITHUB_REPOSITORY, and PULL_REQUEST_NUMBER. That abstraction enables multi-hop dependency resolution, autonomous execution planning, semantic tool orchestration, recoverable missing-state reasoning, and explainable execution traces.

The project explores semantic dependency modeling as infrastructure for autonomous tool-using agents.

  • Core idea: tools produce semantic entities that become requirements for downstream tools
  • GitHub: Cephei18/dep-graph
featured project 06

Decentralized Crowd Funding

A monorepo for an Ethereum crowdfunding dApp using a Solidity smart contract and a React frontend.

The application supports wallet connection, on-chain funding via payable transaction, contract balance withdrawal by owner only, and a read path for cumulative funded amount. The repository pairs a Hardhat-backed Solidity contract with a Vite + React frontend, keeping the stack compact and practical.

Contract design focuses on a simple but complete lifecycle: fund, track lifetime contributions, and withdraw safely with owner-only access control.

  • Tech stack: Hardhat, Ethers, Solidity 0.8.24, Vite, React, ethers v6, npm workspaces
  • GitHub: Cephei18/funding
