Echo — Autonomous Ecosystem Intelligence

An AI-powered intelligence layer for the Base ecosystem that watches governance, grants, and onchain activity in real time and surfaces what actually matters — before it's obvious.

03 · applied ai · the day job

Form Parser — Document Understanding @ MSB Docs

SWE Intern at MSB Docs (Feb–Jul 2026), where I shipped an AI document-understanding pipeline that turns scanned forms and PDFs into interactive, fillable documents — OCR, structural reasoning, and automated field reconstruction, hitting ~85% field recall on messy multi-layout forms.

The hard part was never the OCR; it was the reasoning layered on top of it. I built a multi-stage layout engine — row grouping, ownership propagation, confidence-aware mapping, and table-aware field detection — so the system can make sense of multi-page, semi-structured documents that refuse to follow any single template.

It runs on a production backend (FastAPI, Docker, AWS EC2 + S3), and I led migration planning toward a serverless Textract + Lambda architecture — killing the CPU-heavy OCR bottleneck, sharpening checkbox and table extraction, and cutting infra cost along the way.

Not crypto — but it's the exact instinct behind the onchain work: take something chaotic and unstructured, and turn it into data a machine can actually act on.

  • stack: Python · FastAPI · AWS Textract · Computer Vision · Next.js · Docker · EC2 · S3
  • live: form-pdf-poc-dev demo
  • code: Cephei18/form_parser

06 · agent infrastructure

Semantic Dependency Graph for Tool Planning

A typed execution graph and dependency planner for autonomous agents — built on the bet that agents shouldn't chain APIs blindly, they should reason about what each tool actually produces.

Instead of wiring calls end to end, the system models tools through canonical semantic entities — EMAIL_THREAD_ID, EMAIL_ADDRESS, GITHUB_REPOSITORY, PULL_REQUEST_NUMBER. That one abstraction unlocks multi-hop dependency resolution, autonomous planning, recoverable missing-state reasoning, and execution traces you can actually explain afterward.

An attempt at the unsexy foundation autonomous agents will need before they're trustworthy.

  • core idea: tools emit semantic entities; those entities become the prerequisites for downstream tools
  • code: Cephei18/dep-graph

07 · solidity · the fundamentals

Decentralized Crowdfunding

A compact Ethereum crowdfunding dApp — Solidity contract, React frontend, no bloat. The kind of project you build to make sure you actually understand the full loop, contract to UI.

Wallet connection, onchain funding via payable transactions, owner-only withdrawal, and a read path for lifetime contributions. A Hardhat-backed contract paired with a Vite + React frontend, kept deliberately small so every line earns its place.

Contract design favors a complete, safe lifecycle over cleverness: fund, track, withdraw, with owner-only access control.

  • stack: Solidity 0.8.24 · Hardhat · ethers v6 · Vite · React · npm workspaces
  • code: Cephei18/funding
